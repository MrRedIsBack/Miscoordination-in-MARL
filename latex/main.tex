\subsection{Q-Learning}

Q-learning~\cite{watkins1992q} is an algorithm often used for single-agent learning, but it can also be applied to multi-agent settings~\cite{claus1998dynamics}. In a stateless repeated game, the agent maintains a ``Q-table'' representing the expected reward for each action. Following the simplified formulation of~\cite{claus1998dynamics}, the values are updated by the following formula:
$$
Q(a) \leftarrow Q(a) + \alpha(r - Q(a))
$$
where $\alpha$ ($0 \leq \alpha \leq 1$) is the learning rate and $r$ is the reward received by performing the action.
